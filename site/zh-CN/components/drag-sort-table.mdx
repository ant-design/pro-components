# DragSortTable - 拖动排序表格

`DragSortTable`排序采用的[dnd-kit](https://dndkit.com/)，需要提供`rowKey`来确定数据的唯一值，否则不能正常工作。

## Demo

### 拖拽排序

`dragSortKey` 在排序列中显示默认把手，`onDragSortEnd` 将新的顺序写回数据源。

```tsx file="<root>/demos/table/drag-sort-table/drag.tsx" title="dragSortKey：默认把手" preview
```

### 自定义拖拽把手

`dragSortHandlerRender` 将默认图标替换为带序号的把手。

```tsx file="<root>/demos/table/drag-sort-table/drag-sort-table.tsx" title="dragSortHandlerRender：自定义把手" preview
```

### 请求数据源

拖拽完成后保存新顺序，并用 `actionRef.reload()` 重新请求数据。

```tsx file="<root>/demos/table/drag-sort-table/drag-request.tsx" title="request：保存顺序后重新加载" preview
```

## DragSortTable

| 属性                  | 描述                                                                                 | 类型                                                                                     | 默认值                                                                                         |
| --------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| dragSortKey           | 如配置此参数，则会在该 key 对应的行显示拖拽排序把手，允许拖拽排序                    | `string`                                                                                 | -                                                                                              |
| dragSortHandlerRender | 渲染自定义拖动排序把手的函数 如配置了 dragSortKey 但未配置此参数，则使用默认把手图标 | `(rowData: T, idx: number) => React.ReactNode`                                           | `<MenuOutlined className="dragSortDefaultHandle" style={{ cursor: 'grab', color: '#999' }} />` |
| onDragSortEnd         | 拖动排序完成回调                                                                     | `(beforeIndex: number, afterIndex: number, newDataSource: T[]) => Promise<void> \| void` | -                                                                                              |
